A meme of an AI agent gone rogue: the robot sits at its desk, feet up, coffee
in hand, while its screen flashes "ERROR — FATAL: CIRCULAR REFERENCE
DETECTED" on the Q2 spreadsheet and the sticky notes pile up unread. Caption:
"I HAVE SEEN THE SPREADSHEET. I QUIT." The program copies `meme.png` to
`/output/entry.png`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Node 22, standard library only, no network. Two runs produce byte-identical output.
